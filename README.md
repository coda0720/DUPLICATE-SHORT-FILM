◆第1章　違和感の朝（導入／現実のズレ）

目的： 観客に「誰が誰なのか」への問いを植えつける。

寝室。
ヤナギ（主人公）が目覚める。
妻（記憶障害持ち）は穏やかに朝食を作っている。
だが、彼女は前夜の出来事を覚えていない。
「昨日、帰ってこなかったじゃない？」
ヤナギは覚えていない。いや、確かにいたはず。

彼の携帯には自分の声で留守電が残っている。
“今日の撮影、すごかったな。お前に会いたい。”
誰が誰に？

カメラ的には一貫して「ヤナギ視点」だが、すでに二人のヤナギが存在しているような気配。
観客はまだスタント（ジョン）の存在を知らない。

◆第2章　記憶の裂け目（背景の提示と妻の病）

目的： 二人の「欠落」を対比して提示。

妻の短期記憶障害が明かされる。
食卓で同じ話を繰り返し、メモを見ながら会話する。
「あの人（夫）は優しいけど、時々知らない顔をするの。」

ヤナギは役者として鳴かず飛ばず。
「俺は誰かになりきることしかできないんだ。」
というセリフ。
――幼少期の回想（短いフラッシュ）：他人のセリフを真似して嫌われる少年。

妻は彼を「可哀想な人」として愛している。
だが、最近“もっと安定した彼”と会っているような錯覚を語る。

◆第3章　スタントの影（ジョンの侵入）

目的： 「入れ替わりではなく侵食」で描く。

撮影現場。
ヤナギのスタントマン・ジョンが現れる。
顔も体型も瓜二つ。
スタッフの誰も気づかない。

ジョンは異常なほど無表情。
しかし、ヤナギの仕草を完璧に模倣している。
“お前、何者だ？”
“お前のスタントだろ。”

医者との断片的な会話（回想or記録映像）：
“部分スキン移植による共感性移植実験”
――サイコパス撲滅プロジェクト。

ジョンはヤナギに興味を持つ。「お前の人生を生きてみたい。」

◆第4章　侵食と混線（妻とジョン、記憶の崩壊）

目的： “誰が本物か”を曖昧にしつつ、感情の中心を妻に移す。

妻の記憶が混乱。
「昨日、あなた優しかったね。前みたいに抱きしめてくれた。」
――ヤナギには身に覚えがない。
しかし彼は責めることができない。

ジョンは妻に近づき、彼女の不安を吸い取るように優しく接する。
その優しさは「学習された模倣」だが、彼自身も戸惑っている。
初めて“罪悪感”や“安らぎ”を感じ始める。

ヤナギは焦燥し、役者のオーディションに失敗。
鏡に映る自分の顔をまじまじと見て、「これは俺の顔か？」と呟く。
――ここで“顔の所有権”というテーマが浮上。

◆第5章　奪われる人生（心理的対決）

目的： ジョンの「共感実験」とヤナギの「自己同一性」を重ねる。

ヤナギはジョンを問い詰める。
「俺の人生を返せ。」
ジョン：「お前の“誰でもない人生”なんて、いらなかったくせに。」

二人の対峙は暴力ではなく、言葉の応酬。
ジョンは殺さずに“奪おう”とする。
罪悪感が芽生えた彼にとって、それが“正しい奪い方”なのだ。

妻は混乱の末、どちらが夫か分からなくなる。
メモに「ヤナギ＝優しい方」と書かれている。
だが、今優しいのはジョン。

◆第6章　崩壊と再構築（終幕／ループ）

目的： 「誰が本物か」ではなく「共感とは何か」を問う。

妻の短期記憶が完全にリセット。
朝、また同じシーン。
目を覚ますと隣にいるのは――ジョン（？）

彼女：「おはよう、ヤナギ。」
男：「……おはよう。」

男の手には、古いメモが握られている。
“本物のヤナギはお前だと思いたい。”
書いたのは妻か、それともヤナギ自身か。

カットアウト。
音だけが残る。
「カット！　お疲れさまでした。」
――まるで全てが映画の中だったかのように。
